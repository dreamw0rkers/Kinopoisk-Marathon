## ⚡ О проекте

**Кинопоиск Марафон** — это лёгкое и умное браузерное расширение, которое избавляет вас от рутинных действий при просморте сериалов на Кинопоиске. Больше не нужно вручную ставить паузу, самому проматывать заставки, пропускать повторы или искать кнопку перехода на следующую серию. Все это теперь доступно в одном расширении.

---

## ✨ Основные возможности

| Функция | Описание |
| :--- | :--- |
| ⏭️ **Автопропуск заставок** | Автоматически нажимает кнопки «Пропустить заставку» и «Пропустить титры» без задержек. |
| 📺 **Автопереход к серии** | Мгновенно переключает на следующий эпизод в конце серии. |
| ⏸️ **Умная пауза (Smart Pause)** | Автоматически ставит плеер на паузу при переключении на другую вкладку и возобновляет видео при возврате. |
| 🔔 **Уведомления** | Аккуратные всплывающие сообщения информируют о сработавших действиях (работают даже в полноэкранном режиме). |
| 📊 **Счётчик экономии** | Отслеживает количество пропущенных заставок прямо во всплывающем окне расширения. |
| 🧡 **Интерфейс** | Приятный минималистичный интерфейс в черно-оранжевом цвете. |

## 🛠️ Установка

### Для браузеров на базе Chromium (Chrome, Яндекс Браузер, Edge, Opera, Brave и др.)

1. Перейдите в раздел **[Releases](../../releases)** и скачайте архив `kinopoisk-marathon.1.2.0.zip`.
2. Распакуйте архив в любую удобную папку на компьютере.
3. Откройте страницу расширений в вашем браузере:
   * **Chrome / Яндекс:** `chrome://extensions/`
   * **Edge:** `edge://extensions/`
   * **Brave:** `brave://extensions/`
4. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
5. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с распакованным проектом.
### ♻️ Чтобы обновить:
1. Скачайте готовый `.zip` архив из последнего [релиза](https://github.com/dreamw0rkers/Kinopoisk-Marathon/releases/latest).
2. Распакуйте архив в удобное место.
3. Откройте `chrome://extensions/` в браузере на базе ***Chromium** и включите **«Режим разработчика»** (Developer mode) в правом верхнем углу. _(Если_ он у вас не _включен)_
4. Удалите расширение `Кинопоиск Марафон`.
5. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с проектом.
