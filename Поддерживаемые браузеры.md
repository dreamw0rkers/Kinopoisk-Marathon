# **🌐 Поддерживаемые браузеры | Browser Compatibility**

Расширение **«Кинопоиск Марафон»** разработано на базе манифеста **Manifest V3** и поддерживает все современные браузеры, использующие движок **Chromium**.

## **💻 Десктопные браузеры (Desktop)**

| Браузер | Платформы | Статус поддержки | Примечание |
| :---- | :---- | :---- | :---- |
| **Google Chrome** | Windows / macOS / Linux | ✅ Полная | Основная платформа разработки |
| **Яндекс Браузер** | Windows / macOS / Linux | ✅ Полная | Отлично оптимизировано |
| **Microsoft Edge** | Windows / macOS / Linux | ✅ Полная | Все функции работают штатно |
| **Opera / Opera GX** | Windows / macOS / Linux | ✅ Полная | Работает без ограничений |
| **Brave Browser** | Windows / macOS / Linux | ✅ Полная | Требуется разрешить работы расширений |
| **Vivaldi** | Windows / macOS / Linux | ✅ Полная | Полная совместимость |
| **Arc Browser** | macOS / Windows | ✅ Полная | Полная совместимость |
| **Chromium** | Linux / BSD | ✅ Полная | Полная совместимость |

## **📱 Мобильные браузеры (Mobile)**

Установка на мобильные устройства возможна только в браузеры, поддерживающие внешние Chromium-расширения:

* ✅ **Яндекс Браузер** (Android) — *работает стабильно*  
* ✅ **Kiwi Browser** (Android) — *поддерживает распакованные .zip*  
* ✅ **Lemur Browser** (Android / iOS) — *поддерживает манифест V3*

## **❌ Не поддерживаются (Unsupported)**

| Браузер | Причина отсутствия поддержки |
| :---- | :---- |
| **Mozilla Firefox** | Требуется адаптация манифеста под Firefox WebExtensions API |
| **Apple Safari** | Требуется конвертация проекта через Xcode (Swift API) |
| **Мобильный Chrome / Edge** | Google и Microsoft заблокировали установку расширений на смартфонах |
| **Мобильный Safari** | Использована другая система расширений iOS |

### **💡 Как проверить совместимость вашего браузера?**

Если ваш браузер создан на базе Chromium, открыв служебную страницу chrome://version, вы увидите строку **«Chromium: X.X.X.X»**. Если она есть — расширение будет работать безотказно\!
